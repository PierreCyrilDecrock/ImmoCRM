# supabase/migrations

Fichiers SQL numérotés décrivant la base de données. Claude Code les applique via le connecteur Supabase : d'abord sur le projet de test, puis sur le projet réel une fois l'étape validée et avec l'accord explicite de l'utilisateur. La procédure est décrite dans `.claude/skills/supabase/SKILL.md`. Sans connecteur, le contenu d'un fichier peut toujours être collé à la main dans l'éditeur SQL de Supabase.

Les conventions détaillées arrivent à l'étape 0.5 (`docs/donnees.md`). Aucune migration n'existe encore.
