# supabase/migrations

Fichiers SQL numérotés décrivant la base de données. Ils sont appliqués à la main dans l'éditeur SQL de Supabase : d'abord sur le projet de test, puis sur le projet réel une fois l'étape validée.

Les conventions détaillées arrivent à l'étape 0.5 (`docs/donnees.md`). Aucune migration n'existe encore.
